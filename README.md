# Nostra – E-commerce Website

Nostra is a responsive fashion e-commerce website developed using HTML, CSS, and JavaScript. The project features a modern user interface inspired by the Nostra fashion website, with product collections and interactive functionality.

## Features

- *Home Page:* Fashion banner, brand section, new arrivals, and trending products.
- *Collections Page:* Displays products in a responsive grid layout.
- *Search Functionality:* Search for products by name, category, or tag.
- *Filter Functionality:* Filter products by category and price range.
- *Product Sorting:* Sort products by price or name.
- *Contact Us Page:* Contact form with JavaScript validation.
- *Responsive Design:* Optimized for desktop, tablet, and mobile devices.
- *Interactive Navigation:* Mobile-friendly navigation menu.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser or use the Live Server extension.
4. Explore the pages and test the search and filter features.

## Purpose

This project was created to practice front-end web development, responsive design, DOM manipulation, event handling, and JavaScript-based search and filtering.

*Note:* This is a front-end demonstration project. The contact form does not send actual emails.
